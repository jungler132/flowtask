FlowTask API (1.0.0)
Download OpenAPI specification:Download

REST API для FlowTask.

Аутентификация: Bearer JWT access token в заголовке Authorization.

Большинство endpoint'ов требуют авторизацию. Для мобильных push-уведомлений используйте раздел Notifications.

auth
Аутентификация и обновление JWT-токенов

auth_login_create
Вход по email + пароль. Возвращает один из трёх состояний:

AUTHENTICATED: обычный успешный вход
MUST_CHANGE_PASSWORD: вход временным паролем, требуется смена
PASSWORD_NOT_SET: пароль не задан, нужен OTP-флоу
Authorizations:
jwtAuthBearerAuthNone

auth_set_password_create
Установка нового пароля по change_password_token. Используется в двух сценариях:

после OTP (пароль не задан)
после входа временным паролем (MUST_CHANGE_PASSWORD) После успеха возвращает обычный access_token — пользователь сразу входит.
Authorizations:
jwtAuthBearerAuthNone
Responses
200 No response body
